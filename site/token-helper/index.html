EVBook Token Helper

A browser extension that signs you in to your Tesla account on Tesla's own page and shows you the Owner API access and refresh tokens, so you can paste them into EVBook or any other logger you trust.

Get it from the Chrome Web Store — works in Chrome, Edge and Brave.

Privacy policy

The extension collects nothing. There is no analytics, no tracking and no EVBook server involved.

  • You type your Tesla email and password on auth.tesla.com. The extension never sees them.
  • When Tesla hands back a one-time sign-in code, the extension sends that code to Tesla's token endpoint, and nowhere else, to get your tokens.
  • The tokens are shown on a page inside the extension and held only in the browser's memory while you copy them. They are deleted from the extension's storage as soon as they are shown, and are never written to disk or sent to anyone.
  • No personal data is sold, shared or used for any purpose other than showing you your own tokens.

Why it asks for its permissions

  • auth.tesla.com, auth.tesla.cn — to open Tesla's sign-in page and swap the sign-in code for tokens.
  • webRequest, webNavigation — Tesla finishes sign-in by redirecting to tesla://auth/callback, an address meant for the Tesla app. The extension watches for that one redirect in the tab it opened. It ignores every other page.
  • storage — to remember the sign-in attempt between steps, in memory only.
